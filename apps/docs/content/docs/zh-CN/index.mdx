title: Shukka 简介

---

Shukka 供 Electron 或 Tauri 桌面应用自行托管更新服务。安装包写入自有对象存储，由网页决定何时向用户开放新版本，而无须将安装包交由第三方更新服务保管。

## 它能做什么

- **管理已发布的版本** —— 网页列出各版本及其下载次数，并标示当前向用户开放的版本。
- **使用自有对象存储** —— 支持 AWS、Cloudflare R2 与 MinIO，不同产品可分别配置。
- **安装包不经 Shukka 中转** —— 持续集成将文件直接上传至对象存储，Shukka 不接触安装包内容。
- **已安装的应用自动检查更新** —— 客户端沿用原有更新方式获取新版本，用户无须登录。
- **由持续集成发布** —— 通过 GitHub Action 将本次构建产物上传至 Shukka。
- **上传后默认不发布** —— 版本上传后处于草稿状态，经确认后才向用户开放。

## 快速开始

```bash
docker run -d --name shukka -p 3000:3000 -v shukka-data:/data ghcr.io/shukka-app/shukka
```

打开页面后设置密码即可使用。其他部署方式见[自托管部署](/zh-CN/docs/deployment)。
